## Week 1 - History
- Writing evolved from early visual representations and tally marks into complex writing systems.
- Early writing was often used for practical purposes, such as accounting and record-keeping.
- Different civilizations developed different writing and number systems.
- Printing technology made written information cheaper and easier to distribute.
- Alphabets, typewriters, and keyboards helped standardize written communication.
- Understanding text, characters, fonts, and writing systems provides useful background for working with modern software development tools.

## Week 2 - Bits and Bytes
- Bits and Bytes: A bit is 0 or 1; a byte consists of 8 bits.
- Binary System: Computers use base 2 to represent and process data.
- Memory Types:
 - Volatile memory (RAM) loses data when power is off.
 - Non-volatile storage (SSD/HDD) retains data without power.
- Number Representation:
 - 8-bit unsigned numbers range from 0 to 255.
 - 8-bit signed numbers range from −128 to 127 using two's complement.
 - Floating-point numbers represent fractional values.
 - Text Representation: ASCII maps numeric codes to characters (e.g., 65 = A).
- File Types:
- Text files store bytes interpreted as encoded text.
- Binary files store bytes interpreted according to specific formats.
- Number Systems: Decimal is base 10, binary is base 2, and hexadecimal is base 16.
- Number Conversion: Practice converting binary and hexadecimal numbers into decimal.
- Historical Technologies: Morse code, punch cards, and teleprinters were early methods of communicating or storing information.
- Files and Data: All computer files consist of bytes, and software interprets those bytes according to the file's format.
