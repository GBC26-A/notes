## Week 1 - History
- Writing evolved from early visual representations and tally marks into complex writing systems.
- Early writing was often used for practical purposes, such as accounting and record-keeping.
- Different civilizations developed different writing and number systems.
- Printing technology made written information cheaper and easier to distribute.
- Alphabets, typewriters, and keyboards helped standardize written communication.
- Understanding text, characters, fonts, and writing systems provides useful background for working with modern software development tools.

## Week 2 - Bits and Bytes
- Bits and Bytes: A bit is 0 or 1; a byte consists of 8 bits.
- Binary System: Computers use base 2 to represent and process data.
- Memory Types:
  - Volatile memory (RAM) loses data when power is off.
  - Non-volatile storage (SSD/HDD) retains data without power.
- Number Representation:
  - 8-bit unsigned numbers range from 0 to 255.
  - 8-bit signed numbers range from −128 to 127 using two's complement.
  - Floating-point numbers represent fractional values.
  - Text Representation: ASCII maps numeric codes to characters (e.g., 65 = A).
- File Types:
- Text files store bytes interpreted as encoded text.
- Binary files store bytes interpreted according to specific formats.
- Number Systems: Decimal is base 10, binary is base 2, and hexadecimal is base 16.
- Number Conversion: Practice converting binary and hexadecimal numbers into decimal.
- Historical Technologies: Morse code, punch cards, and teleprinters were early methods of communicating or storing information.
- Files and Data: All computer files consist of bytes, and software interprets those bytes according to the file's format.

## Week 3 - Text Structure
- Text Structure: Organization of text using lines, indentation, and paragraphs.
- Markup Languages:
  - Markdown: Simple syntax for headings, bold, italics, and lists.
  - HTML: Uses tags to structure and format content.
- Special Characters and Escaping: Use escape sequences and HTML entities to display special characters correctly.
- Structured Data:
  - JSON: Lightweight format for data exchange.
  - XML: Uses tags to represent data.
- GitHub: Supports version control, collaboration, and Markdown documentation.
- Unicode: Represents a wide range of characters using code points and encodings such as UTF-8 and UTF-32.
- Browsers: Interpret HTML, CSS, and JavaScript using rendering engines like Blink and WebKit.
- Lab Exercise: Edit Markdown on GitHub and submit screenshots of the rendered result.

## Week 4 - Keyboards & Editors
- Overview: Text manipulation tools and techniques for software development.
- Keyboard Mastery: Learn keyboard layouts (QWERTY, AZERTY, Dvorak), modifier keys, and touch typing for efficiency.
- Text Editors: Distinguish word processors from text editors; learn Vim (:q!) and VS Code. IDEs include WebStorm and PyCharm.
- Search Techniques: Use Ctrl + F for basic search, wildcards (*), and regular expressions (e.g., line\d+).
- GitHub Pages: Host websites from GitHub repositories and customize themes through _config.yml.
- Practical Tips: Use Ctrl + D in VS Code for multiple selections and GitHub for version control.
- Recommendations: Practice typing with Keybr or Ratatype, become familiar with VS Code, and learn regex using Regex101.

## Week 5 - CLI
- CLI History: Evolved from teletype machines to modern screen-based terminals.
- Advantages: Fast, lightweight, automatable, and useful for remote access.
- Basic Commands: `ls`, `cd`, `pwd`, `cat`, `less`, `cp`, `mv`, `mkdir`, and `ping` for navigation, file management, and connectivity.
- Advanced Commands: `grep` searches text; piping and redirection manage command input and output.
- Remote Access: SSH connects securely to remote computers; SCP and SFTP transfer files securely.
- Tools and Utilities: `htop` monitors system resources; `tmux` manages multiple terminal sessions.
- WSL: Runs Linux tools and commands within Windows for development.

## Week 6 - Git
- Version Control: Tracks project changes and prevents confusion between file versions.
- Git and GitHub: Git manages versions locally; GitHub hosts Git repositories online and supports collaboration.
- Basic Git Workflow: Clone → Pull → Modify → Stage → Commit → Push.
- Diff and Patch: Compare file versions and apply changes.
- Git in VS Code: Use Source Control to review changes, stage files, commit, and sync.
- Branching: Enables parallel development through branches such as `main`, feature, and bugfix branches.
- Merge Conflicts: Occur when changes overlap and require manual resolution.
- Key Concepts: A repository stores project files and history; a commit records changes; a branch represents a separate line of development.
- Best Practices: Commit often, write descriptive messages explaining why changes were made, and communicate with teammates.
